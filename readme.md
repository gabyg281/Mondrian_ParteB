# Parte B — Desestabilização

Nesta segunda fase do trabalho, optei por quebrar a ordem rígida de Mondrian através de uma simulação de instabilidade nos quadrados coloridos da obra. A grelha geométrica mantém-se estática e perfeita, mas as cores "respiram" e corrompem-se de forma subtil.

Para implementar esta animação usando o sketch da Parte A, tive de otimizar o código, isolei a textura gerativa pesada numa camada gráfica independente (createGraphics), evitando que o ciclo contínuo da animação acumulasse ruído visual até escurecer a obra. Após resolver esta sobreposição, introduzi o tempo (frameCount) como input para criar uma função de oscilação baseada no seno (sin()). Esta funão altera subtilmente os valores RGB das cores, gerando como output uma desestabilização contínua e orgânica que injeta vida na composição sem destruir a sua essência geométrica.
